# 界面按钮审计 — 2026-08-11

## 范围

本审计依据 `docs/UI_SYSTEM.md` 检查 Vue 界面的按钮层级与主题色使用。动作、选中、状态和进度必须分开判断，不能因为都可点击或都重要就使用相同视觉。

## 本轮已完成

- `WorkView.vue`：删除页面私有的主按钮、次按钮、紧凑按钮和图标按钮定义，全部改用公共原语；
- `GlobalDialog.vue`：确认、输入、取消和明确的破坏性确认统一使用全局层级；
- `ConfirmCard.vue`、`BrowserEnableCard.vue`：删除 scoped 按钮系统，改用公共主次按钮；
- `SettingsConnections.vue`：删除重复的危险描边定义，连接销毁等动作改用公共规则；
- `index.css`：明确主次、紧凑、选中、危险描边、最终危险、禁用、焦点与图标按钮行为。

复查后，源码中不再存在对核心 `.btn`、`.btn-primary`、`.btn-secondary` 或 `.btn-icon` 的 scoped 重定义。

## 可以保留主题色的状态

- 已选中的对话、笔记、标签、模型角色和项目；
- 今天、当前导航和当前步骤；
- 进度条、运行中指示、焦点环和实时状态圆点；
- 已选择行或已关联文件的浅色表面。

## 延后迁移的兼容界面

| `ChatView.vue` | 发送、Runtime 与工具控件类型较多 | 先区分动作和实时状态，禁止批量替换进度/状态主题色 |

## 防回退规则

后续审查应检查公共类是否被 scoped 重定义，以及普通提交按钮是否又出现主题色实心背景。只有明确表达选中、当前或进度状态，或经过记录的例外，才允许新增主题色填充。
