## 2026-11-17 正式项目边界、运行态隔离与集群自主权限

- **正式项目目录对齐 SSOT 与 `bob-agent` / `bob-bot` 分立**：`project_registry.yaml` 同步平台正式项目清单，将 `bob-agent` 与独立原型实验室 `bob-bot` 严格分开；AI 自动整理不再收集非正式桶，收集箱下拉仅保留正式活跃项目并新增「+ 手动输入新项目...」显式创建入口。
- **排除运行态守护进程与侧栏测试折叠**：过滤 `/opt/*` 非 Bob 启动的常驻运行态服务（如 `bob_project: false` 标记的 `Quant Bot`）；测试探针统一归入 `__bob_test_archive__` 隐藏哨兵，泛型目录探索与旧导入会话默认折叠收纳。
- **节点工程会话三档权限预设**：主力工作节点原生与 DSH 会话默认启用「跨目录与远程部署（`full_auto`）」以消除 `ssh`/`git push`/构建误拦（仍支持手动降级为「工作区自动读写」或「只读」，并硬拦截删根/强推/删表与问答）；L1/L2 个人与办公 `Action Gates`、`Draft` 及人工审批门禁保持完全独立不降级；执行记录默认折叠，待批项独立成卡并带悬浮快捷确认条。

## 2026-11-17 主助理长期记忆、多问题覆盖与连续性

- **分层长期记忆（`WP-E1-M`）**：主助理在同一运行主机持久化有来源和作用域（当前会话 / 关联项目 / 全局偏好）的长期记忆，结合 16 条阶段摘要及有界相关历史召回；支持对话中 CAS 纠正和事务内遗忘，遗忘后切断旧上下文自动召回并拒绝旧审批。
- **多问题逐项覆盖与连续性（`WP-E1`）**：同会话按 `request_id` 边界恢复近期窗口，主助理可直接通过 CAS 原位修改已有待办/日程（保留原备注与未指定时间），修正默认 DeepSeek API 模型名称；复杂多问题逐项登记回答/等待/失败并在补核对阶段不重复写操作。
- **验证状态**：258 项定向回归与 Gemini/DeepSeek 跨 24 条消息、重启、切换模型等真实验证已通过并发布网页后端；本轮无 APK，浏览器视觉与手机真机终验待完成。详见 [长期连续性证据](evidence/2026-11-17-assistant-memory.md) 与 [主助理连续性证据](evidence/2026-11-17-main-agent-continuity.md)。

## 2026-11-16 日程 ISO 防偏移门禁、可插拔多参谋长与 PWA 推送

- **日程/待办确定性 ISO 日期防偏移**：主助理工具入参全面切换本地 UTC+8 ISO 日期字符串，内核硬拦截三年往回偏移或跨度异常日期幻觉，并支持主对话/审批结束后自动刷新个人事务面板。
- **可插拔多参谋长 MCP 总线（`BOB-D-017` / `WP-C1`）**：新增 `chief_service`，支持外部参谋长读取脱敏战报（`bob_briefing`）与提交标准化指令（`bob_order_submit`），统一进入 Jarvis 人工审批队列，随时撤销席位即刻生效。
- **待批唤醒推送与安全增强**：接入手机/桌面浏览器 VAPID Web Push 审批提醒与 iOS PWA 引导；节点终端支持 `bob-node qr` 紧凑二维码打印，Android 端提供可选系统生物识别启动安全锁。
