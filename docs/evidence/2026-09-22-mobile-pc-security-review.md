## 外部审计的校准

- 不能扩大成“整个项目没有加密”：`web_drop.rs` 存在文件块加密；其密钥交换和端到端保证需独立审核。`crypto.rs` 本地私钥加密也不等于同步 E2EE。
- 当前 `progress.yaml` 是 0.9.6，不是外部报告的 0.5.0；发布包与工作树需分别核实。
- MCP 与 ACP 都可能用 stdio JSON-RPC，但协议语义不同；只能复用进程与传输基础设施，不能视作已完成 ACP 适配。
- Tailscale 是个人部署可选传输方案，不替代应用授权，也不是开源用户必装依赖。跨设备不能直接访问另一设备的 127.0.0.1，需明确代理/监听映射。
- “没有 CSS 断点”不足以判定移动体验失败；需要实机/目标视口验证。“零知识证明”不应作为 AES-GCM 的同义词。
