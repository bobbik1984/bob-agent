## 实现及代码基线

网页版本 `dsh-paging-20261031-r1`。基线提交 `4186208ced91839cefe9f1efecb11d032cfa412b` 加既有与本轮未提交修改；以 source-manifest 和 deployment 回执固定实际制品，不把 HEAD 当作完整发布代码。没有覆盖其他 Agent 修改、提交或推送仓库。

DSH runtime 使用当前实际运行版本的原生 session/page、follow snapshot 与 projections 契约。首屏投影最近10条可见消息，固定 throughSeq/beforeSeq 读取更早页面；按 sequence 去重并保留 surfaceOp 替换语义。无变化轮询仅取 projections，不重复取正文。批量新消息补齐中间页后才推进游标，失败保留原窗口。页面响应绑定原连接/会话；切换后迟到响应不会污染新会话。

历史区独立滚动，输入区位于同一固定高度容器的底部。首次定位最新；向上触顶加载更早10条并恢复视口锚点，保留草稿。三点菜单改为紧凑图标与文字列表，分组、外部点击关闭、Escape 关闭及焦点恢复。沿用主题和中英翻译。

变更范围：bob-runtime/dsh_transport、bob-node 命令、kernel-bridge、DshSessions、App 菜单及全局样式、双语文案和手机回执回归。Cargo.lock 仅纠正多版本 base64 引用为 0.22.1，没有升级依赖。

## 发布与恢复

生产空闲、SQLite/data副本、旧二进制读取新数据兼容、完整源码校验通过后，备份并切换生产；deployed=true，rollbackUsed=false。具体 hash/备份位置见 deployment.json。回退恢复已备份程序和网页，保留发布后数据，不能用旧库覆盖新消息。首次预检因 Cargo.lock 的版本歧义变动拒绝，修正锁文件并重构建后通过；保留这项失败，不冒充首次成功。

生产浏览器通过私有 SSH 通道访问实际生产端口；不是独立公网登录验收，也不是手机真机。APK 未构建，Tauri 分页命令接线/真机仍待补。B4/Blender未恢复。

## 限制和后续

每次页面读取有32请求/20秒/16MiB预算，达到边界可能少于10条，错误不清空已有记录。附件读取仍限当前原会话引用与工作目录/2MiB边界；加载旧消息不意味着其全部历史附件可读，不将当前文件视作不可变成果。继续沿原待办补 Tauri、精简 DSH 传输、结构化成果与 ArtifactVersion，不另立路线。

初版以原生 maxMessages=10 尝试时，32次请求仍只投影9条可见消息，验证失败；已改为原生有界批次100、表层10条及空闲游标检查。截图仅留本地临时审计目录，仓库只保留无正文/无凭据的结构化指标。
