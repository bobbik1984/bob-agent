# AGY 原生发现与续接核验

## 范围与事实

- 用户授权：X1T 统一设备入口、AGY 原会话发现/历史/续聊；暂不上线、不打包，手机暂停。
- 目标端实际 AGY 1.4.10，帮助支持 --conversation、双向 stream-json、plan 和 print-timeout。官方 remote-control daemon 状态 inactive；未启动或安装服务。
- 只读 SQLite 索引初查18条记录；正式发现模块排除子会话后14条主会话，其中8条对应本地数据库，6条索引无本地数据库。不是14条均可读取历史。
- 当前旧历史 steps.step_payload 为二进制 blob；未找到可核查的公开解码契约。本实现不猜测角色或抓取终端屏幕，不将缺失历史伪装成空对话。
- 使用已有 Sea2 会话发一次不调用工具、不读写文件的进度询问。官方 CLI 返回 exit 0、SUCCESS、同一 conversation_id；回复正确描述海路纪元地球视觉渲染主题。没有重试、没有新建会话。提示约束不等同于独立全工作树哈希验证。
- 原始会话ID/正文不写入此脱敏证据。

## 实现与验证

crates/bob-runtime/src/agy_index_probe.py 为只读宿主发现辅助程序：配置传入数据目录、SQLite mode=ro/query_only、查询预算、最多200条、标题/URI上限、UUID校验、排除子会话、明确缺失和不支持的历史状态。不会读取凭据，不从索引存在推断认证。

Python测试3/3通过：真实SQLite排序/限量/原文件不变、未知schema拒绝、缺失数据库不创建。首次测试暴露连接未关闭，已修复并重跑。正式源码通过SSH stdin在真实X1T执行，得到14/8/0的主会话/本地历史/可读历史统计，退出0。
