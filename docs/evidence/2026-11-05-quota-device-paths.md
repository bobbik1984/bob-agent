# 额度真实性与设备路径修复候选

基线：`ffa8bf4`（1.0.1）。目标：消除截图中的示例额度、混淆的连接状态，并提供显式设备多路径归组。

## 代码变更

- 删除固定订阅余额、以本机token/步骤数和假定预算计算订阅额度、用任意周周期推算重置进度的后端逻辑。未接入官方认证额度源时返回unavailable；前端不再使用旧百分比或示例预付费金额，不扫描其他进程会话日志来冒充当前账户额度。
- 新增可持久化deviceId，路径仍使用原连接ID与原凭据槽。旧调用保存时保留已确认分组与附加配置；没有ID时同地址重复添加复用原路径ID。配对拓扑的分组元数据可同步，认证边界不变。
- 不再因保存了令牌就把连接标为在线；刷新失败清除在线观测但保留网络故障时仍有效的凭据。设置中一个设备卡片列出其路径，支持添加路径、明确选择所属设备及逐路径测试会话读取。分组仅来自明确deviceId，不按名称/域名猜测。读取观测有路径范围与时效，旧请求不覆盖新观测；已有路径筛选跟随明确的设备归组，不因分组后改键而隐藏原记录；编辑凭据或删除路径清除该路径观测。
- 会话目录按设备归组，保留每条记录原连接ID与来源路径。失败提示具体路径，保留缓存时明确说明；配置移除后清除对应旧失败提示。不依据同名会话合并不同工具实例，未决发送不自动重发，没有增加自动路径切换。
