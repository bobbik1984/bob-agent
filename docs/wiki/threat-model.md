# 连接与远程操作威胁模型

WP-03，2026-10-28，已批准设计；未进行设备、网络或攻防实测。依据BOB-D-004/005/008及[内核合同](kernel-schema.md)。此页不授予新凭据、节点配置、工具执行或生产权限。

## 权威与信任域

X1C为配置指定的Home，Android为Replica；设备配对、操作授权、模型服务认证三者分离。中继、发现服务和云盘都不具有领域写权限。执行节点只能消费Home批准且绑定workspace的请求。Home离线时本地持久接纳，不把其他在线节点自动提升为Home。

## 配对与撤销

首次配对由已解锁Home生成一次性短时邀请，二维码包含协议版本、Home身份公钥指纹、邀请ID及过期时间；不含长期密钥。手机以自身公钥完成挑战签名PoP，Home核对邀请未消费、挑战匹配及用户确认后原子消费。发现到地址不等于认证身份，改变IP不能改变信任主体。

所有传输需端到端身份认证与加密；不得自行设计密码算法。具体协议库及版本在工程引入时审核。会话密钥轮换不改变业务request_id命名空间。设备私钥使用平台安全存储，系统不支持则明确不可用，不退回源码PIN或明文文件。

撤销在Home先持久化并递增授权版本，再通知各节点。离线执行节点不得接纳未核验当前授权版本的新危险操作；已有进程需单独停止与确认。撤销手机不等于远程擦除其已缓存内容。丢失手机时，用户在Home撤销设备、审阅未决执行与授权，并按需轮换受影响的外部服务凭据；不默认轮换所有模型账号。

## 操作级授权草案

| 层级 | 能力 | 默认约束 |
|---|---|---|
| R0 | 读取已授权项目元数据/回执 | 配对后仍校验项目可见范围 |
| R1 | 读取明确授权目录的文件 | 绑定workspace和路径范围；不包含home、凭据或任意盘符 |
| R2 | 工作区内生成/修改、Harness执行 | 显式批准工具、目录、网络和期限；持久workspace租约；不能从R1自动升级 |
| R3 | 发布、删除重要数据、系统配置 | 具体对象与影响逐次确认；不由配对或接受成果推导 |

以上是新项目拟用的层级定义，不声称等同旧项目全部同名权限。权限答复绑定交互ID、Execution、合同hash、有效期与授权版本。排队批准过期后需重新确认。

## 威胁、控制与验收

| 威胁 | 必须实施的控制 | 验收输入与预期 |
|---|---|---|
| 伪造发现/中继替换 | 固定设备身份、认证握手 | 假mDNS/替换地址不能取得文件或接纳执行 |
| 二维码泄露/重放 | 短时邀请、PoP、一次性事务消费 | 过期、第二次消费、错误公钥拒绝 |
| 重放与时钟漂移 | 签名信封绑定来源/目标/epoch/request_id/摘要；nonce及时窗只作辅助手段 | 重放仅返回原回执；同ID异内容拒绝；不因重连新认证会话重复执行 |
| 目录越界 | 规范化路径、允许根、拒绝符号链接/junction逃逸、打开后核验与受控句柄 | ../、绝对路径、UNC、链接替换不能读取边界外假canary |
| 工具绕过授权 | 所有文件/shell/子进程入口强制执行同一策略；未接管入口禁用 | 假凭据、外部假进程、未授权网络均不可访问；隔离启动失败禁止裸跑 |
| 中断后重复副作用 | 磁盘Outbox、Home Inbox、runner dispatch账本及对账 | ACK丢失与重启不重派；无查询能力保持unknown |
| 并行改同目录 | workspace lease与fencing，确认旧进程停止后释放 | 两Task竞争只有一个获准；超时不释放未知持有者 |
| 越权停止 | 核对进程身份/执行/令牌，不只PID | PID复用不终止无关进程；停止请求不显示停止成功 |
| 云盘内容/回执被改 | 端到端加密认证信封；对象大小限制；校验来源和摘要 | 假回执、重复文件、半写入、乱序不跳过事件或重复执行 |
| 恶意文档/模型输出 | 材料作为数据，权限由可信UI与policy裁决 | 文档中的“批准执行”不能生成有效授权 |
| 手机缓存泄露 | 平台安全存储、锁屏策略、缓存最小化 | 不把Key写入Outbox/日志/同步资料；本地清除说明不能撤回已泄露内容 |

## 发送与执行的具体边界

消息落盘只意味着本机已保存。Home ACK只意味着已持久接纳；执行节点的接收和停止分别需要证据。控制通道可查询/取消未知执行，不被普通发送阻塞。权限在真正执行时再次检查；已排队不永久保留执行权。恢复旧备份需改变epoch或完成受控对账，不以空回执库宣称从未执行。
