# Bob — 设计与交互原则

订阅双线固定展示周窗口：Antigravity取gemini-weekly，Codex/Claude取weekly。余额与重置时间来自同一窗口；缺失不得以短周期或第三方模型额度替代。

用户确认来源：2026-10-31 当前对话。本文是 App、悬浮窗及网页端共同的设计约束；实现和验收状态见 CURRENT_STAGE，不因写入规范而视为已实现。

## 视觉语言

- 简洁、现代、直观清晰，保持温和的交互反馈；保留正式 Bob 品牌资产。
- 产品导航、按钮、状态、空态、设置和内置文案不使用 emoji 作为图标或装饰；使用统一 SVG 图标。用户正文和模型原始回复不因此被过滤。
- 顶栏连接入口显示连接目标的 SVG 图标与右上角单实心状态点（不常驻显示名称，完整名称保留可访问标签及详情），无外圈或光晕。图标表示对端，不表示正在使用的手机/电脑；设备类型只能来自可信设备元数据，未知类型使用 Home/通用图标，不按屏幕大小猜测。网页直连显示网页节点；已配置不等于在线，在线不等于模型可执行。点击直达设备连接子页。
- 已配对、当前可达、可执行分别表达；绿色不能仅由保存了凭据或完成配对决定。详细原因在点击后的面板中显示。
- 颜色全部来自主题语义变量；新增文字同步中英文。样式克制不能以删除可访问名称或焦点反馈为代价。

## 首次打开与历史恢复

默认：首次进入或原会话不可用时打开本实例持久的助理对话（BOB-D-012）；上次明确选中的有效会话可恢复，侧栏固定“助理”入口随时返回。不要求先选择项目或节点。用户主动新建的普通空白对话仍在首次发送时创建，不能把历史导入当默认助理。

旧数据导入、后台刷新、服务器重启不能选择会话，也不能修改用户的阅读位置。显式会话链接可定位目标；历史项目继续在列表中可找，不因修复入口而删除。网页客户端选择不能默认被另一客户端覆盖。

验收：导入旧项目后当前选择不变；服务重启保留用户选择；新客户端无旧选择时空白；旧选择被归档时有合理回退；两客户端切换互不抢焦点。

## 悬浮窗：快速记录灵感

核心动作是本地可靠保存。打开时进入轻量新记录；存在未保存草稿时恢复草稿。键入后在输入区下方出现紧凑的归属选择：不关联项目、最近/搜索已有项目、新建项目。关联可选，不阻塞保存，不因选择项目就启动模型或创建开发 Task。

项目选择与草稿一起保存；新项目在确认保存时创建，取消不留下空项目。记录保存后可继续讨论、转为待办或提升为 Work，保持原始来源。输入期间减少其他菜单，但不能隐藏正在进行的保存/失败状态。

模型切换从悬浮窗高频工具中移到设置或高级选项。连接扫码保留在设备入口；拍照记录是另一项能力：拍摄→预览/重拍→保存原图→识别建议→用户校正/确认。识别失败仍能保存照片，不能把识别文本自动当成已确认决定或提醒。相机权限拒绝时提供系统选图入口（实现后才显示可用）。

悬浮窗内部不重复显示 Bob Logo；品牌保留在正式入口。文字编辑器与外层面板只呈现一处克制的焦点反馈，禁止叠加默认亮蓝内圈；按钮仍须保留键盘焦点。图片/识别内容展开后整个面板须保持在动态视口内，全部按钮能滚动触达。

文字、拍照与选图是记录入口；扫码配对只属于“设置 → 设备连接”。照片先保存原件再按用户点击识别，调用前展示已配置的视觉模型与服务去向，不沿用聊天模型作为静默兜底。识别建议可编辑，须明确加入记录；失败保留原图和文字。未配置视觉服务也可保存图片。相机选择由系统能力决定，不能把文件选择器或桌面浏览器测试称作手机相机验收。当前实现和验证边界见 CURRENT_STAGE。

## Agent 修改入口与检查

修改可见 UI 前必读本文、FEATURES 与当前组件。完成时检查无产品装饰 emoji、主题/i18n、无虚假连接状态；以实际浏览器及适用手机操作验证首屏、项目选择、草稿和错误提示。自动扫描排除用户内容与测试数据，检查通过不代替交互验收。

## 主题强调色与日历

强调色在根主题令牌中统一定义明暗色阶，组件仅引用语义变量。普通模式不直接使用平台 Highlight（移动浏览器可能映射成低对比浅色）；高对比辅助模式保留系统色。可用发送按钮与选中图标必须可辨认，禁用态单独表达，不能靠加重所有背景解决。

捕获入口统一称为“灵感速记”。日历小时栏每格完整铺底，数字水平和垂直居中，使用等宽数字并缩窄栏宽。小时仅显示整数，午夜 00 显示为 0，其余 1–23 与真实起始小时一致（屏幕阅读标签保留完整区间）；事件时间在悬停、详情和可访问标签保留完整时分，不能为简化标签改变时间映射。

## 连接页按使用目的组织

主入口仅区分连接我的电脑（电脑展示二维码，手机扫码）与连接远程Agent（服务地址和令牌、已有会话）。Home/Replica、指纹、恢复和手动邀请属于排障，不默认展开。网页节点自身可达不等于电脑配对；连接已保存不等于在线。功能未接通不显示可提交的假表单。凭据传输不能用“自动双向同步”笼统承诺。连接后应逐步呈现具体设备/服务卡片，项目与会话统一在对话侧栏查看。

日历事件使用统一面层和细边框，不用装饰性深色侧条。点击事件打开可编辑详情卡片，点击空白时段打开预填日期时间的新建卡片；弹窗不插入页面文档流。提供明确关闭及 Escape 退出，返回后保留日历位置；保存失败保留输入，版本冲突不能覆盖他端修改。

日历工具栏日期、周切换与视图切换保持一行；周切换用左右箭头，回到本周用定位图标，视图用日历/列表 SVG。所有图标保留本地化可访问名称和悬停提示；窄屏缩短日期显示，不删减操作。回到本周必须定位真实当前周，不因历史测试事件改变基准周。

## 会话阅读与长内容

显式进入会话默认展示最新区域，不恢复过期的中段滚动偏移。停留底部时，图片解码、流式正文和容器尺寸变化继续保持底部；用户主动上翻后保留首条可见消息及其屏幕偏移，不抢回底部。离开最新区域显示带可访问名称的向下箭头，点击返回最新。成果预览关闭与同次菜单切换保留原阅读位置。

普通回复与工作会话历史共用消息阅读组件。用户输入保留原文，助手正文按安全的 Markdown 子集渲染标题、强调、列表、引用、表格和围栏代码；不执行原始 HTML。不支持的语法保留可读文本，不能隐去内容。复制操作保留原始正文。

长正文自然撑开，会话区域承担纵向滚动，不给单条消息设置固定高度截断；代码和表格可单独横向滚动，不能推宽整个页面。键盘可聚焦滚动区；阅读历史时刷新不得强行跳至末尾。末尾必须位于输入框上方。

节点相对文件路径不能直接解析为当前网页路径；未接通的附件显示文件路径和不可读取说明，不展示破图。外部图片当前提供显式查看链接，不自动请求第三方图片。真实远端会话接入后仍须验证长历史、附件访问和断线恢复，不能用排版样例替代链路验收。

## 侧栏目录

零对话项目默认不在对话侧栏展示；只有当前客户端明确新建成功的空项目临时保留 30 分钟（关闭再打开侧栏仍保留，整页重载结束临时显示）。增加对话后按普通分组展示。刷新目录不能把旧项目重新标成新建。隐藏仅是视图行为，不删除项目资料；清理必须核对会话关联、决定及其他引用，不能凭对话计数为零删除。

会话元信息中的Harness采用本地静态logo（16px等比适配），不重复占用文字宽度；保留title/alt可访问名称，未知工具回退文字。DSH复用DeepSeek图标；Pi使用官方项目logo。不得运行时依赖第三方图片CDN。

抽屉只有纵向滚动；长标题可收缩省略，操作始终可见。项目默认折叠，当前项目展开；搜索同时匹配项目和会话。最近活动来自消息或新建时间，阅读/刷新不改变排序。历史导入明确标识并默认收起，不冒充节点实时目录。

### 原生节点会话与空白对话

- 空白对话不沿用目录中旧项目的标题；真实消息与选中会话一致后才显示其标题。
- 节点原生会话以连接ID和会话ID寻址，按报告的工作目录分组、最近活动排序。历史导入独立收起，不能与实时列表混为一谈。
- 长历史使用正常纵向阅读；Markdown表格/代码局部横向滚动。发送中、节点接收、回复出现、回执未知分别表达；不自动重发不确定请求。

## 统一对话入口

对话不按Chat/Work划分主导航。原生节点与本地会话共享侧栏、搜索和最近活动排序，每条显示设备标签；按项目或设备分组只改变目录视图，不合并会话身份。旧导入记录默认收起。连接、凭据、模型与执行配置归设置；成果和进展仍紧贴对应对话。未接通的旧Online专项任务控件保留高级入口，不能冒充原生DSH会话。

项目组标题使用“设备短名 / 项目名”，完整工作目录只作提示与搜索依据。项目子会话缩进，独立会话保持根级；分组身份保留连接ID与完整目录，不能因同名合并。没有可信系统类型时使用通用设备SVG，不猜测操作系统。


### 沉浸与文件阅读

底部导航按实际入口数量均分，不保留移除入口的空列。沉浸为客户端显示偏好，只隐藏导航与捕获浮钮，三点菜单始终能返回列表、设备和设置；会话、草稿、停止与错误不因模式变化而改变。文件预览用覆盖层，关闭恢复原阅读位置和焦点，预览时不替换底层历史。当前工作区读取与已冻结成果版本必须用不同说明，不能以当前文件冒充历史交付。


### 长会话与操作菜单

原会话首次读取最近10条可见消息并定位底部；向上触顶按权威游标读取更早10条，去重、替换语义及阅读锚点必须保留。输入区在滚动区之外始终可见；翻看旧内容不被新回复拉到底部。更多菜单使用紧凑图标与文字行、必要分组，支持点外部及Escape关闭，不堆叠大尺寸表单按钮。

### 成果准备与缓存

当前可见成果从新到旧顺序准备，不并发下载整个历史。自动预取有数量、单文件和内存上限；相同身份/游标/路径共享一次请求。无总字节进度时只显示正在准备，不虚构百分比。当前工作区缓存有时效，不当成历史快照。侧栏和最近正文先显示本地已读取内容、后台核对更新，刷新失败保留旧内容并提示；不能每次打开先清空。正文按权威游标分页，固定游标页可以复用。阅读缓存统一限定载荷字节数、条目数和有效期，按最近使用淘汰；不得清理发送账本、未知回执、草稿或正式项目对象。连接修改/删除失效所属缓存。文件以服务端版本与大小核对变化，不用Session ID单独判断文件未变。缩略图可先显示已下载副本，点击打开同一副本并明确缓存语义；服务端缩略图未接通前，不通过下载原图再缩小宣称首次流量下降。


## 远端会话消息与处理提示

用户消息用收窄右对齐的主题面层卡片及完整内边距，与助手正文的完整阅读宽度区分。已送达不代表正在思考；仅根据节点真实running观测显示正在处理，网络读取失败清除旧观测。等待回复按请求ID匹配终态，不能因他人的回复或记录更新自动宣布本次完成。

### 订阅额度双线

菜单每家使用同一行布局：Logo、上下双线、右侧额度百分比与剩余时长（如2d 4h）。名称与来源不常驻占位，保留可访问名称和悬停详情。上方额度线由绿渐变至红；下方时间线为白色；右端固定，剩余量减少时左端向右缩短，空出部分保留主题令牌quota-track（当前确认值#333333）。固定选择周窗口（Codex/Claude weekly，Antigravity gemini-weekly），不回退五小时窗口；悬停标明窗口。时间比例仅在已知官方窗口周期时计算，未知数据使用短横线、过期数据加标记，不把未知显示成0%。

Android正式标识由现有Bob矢量路径生成，常规与自适应前景分开画布；自适应前景保留安全留白，避免圆形裁切。重生成入口：在apps/bob-app运行pnpm exec tauri icon src-tauri/icons/bob-icon-manifest.json --output <external-output>，经视觉检查后归入icons/android；CI生成壳后staging覆盖，保留包标识与固定签名。


## 五栏导航、单一收集箱与每日分拣卡（BOB-D-014，设计规范）

- **五栏导航职责边界**：
  - **对话（Chat）**：主助理对话与各项目工程会话。
  - **今天（Today，原“日程”）**：聚焦时间与今日行动（今日议程、待办事项、定时任务），不再混入未分拣灵感。
  - **收集箱（Inbox）**：唯一灵感入口，承载未分拣火花（`unsorted`）与每日分拣确认卡（Daily Review Card）；未分拣数量以温和角标提示，不制造红色警报焦虑。
  - **知识（Knowledge）**：仅承载已分拣沉淀的笔记、决定与记忆。
  - **我的（Avatar / Profile）**：设置、设备连接、模型配置与票夹统一入口（票夹不再多处重复展示）。
- **零决策快速捕获（Zero-Decision Capture）**：
  - 手机、Web 与桌面悬浮按钮统一指向「收集箱」，支持文字、照片或语音输入，输入即存、无需在写入时纠结项目归属或分类标签；离线时先存本机 Outbox，联网自动同步。
  - 已分拣（`sorted`）条目不从收集箱历史中抹除，而是保留指向去向的胶囊标签（Destination Chip，如目标项目 `todo.md`、日程或笔记）。
- **每日分拣确认卡（Daily Review Card）与视觉表达**：
  - 每日分拣结果以卡片堆叠（Card Stack）呈现，每条建议附带彩色去向胶囊（`Project todo` / `Calendar` / `Note` / `Merge` / `Keep`）及「确认 / 改一下」或「全部确认」操作。
  - 视觉演进方向（柔和蓝底面层、大圆角白卡片、主操作强调蓝与语义状态胶囊）必须 100% 映射至系统级 CSS 变量（`var(--bg-*)`、`var(--accent-primary)` 等），严禁硬编码色彩值，确保亮色与暗色模式（Dark Mode）同等和谐。

连接设置的列表卡片与扫码配对卡片共用外层宽度；可折叠容器不额外叠加左右内边距。展开间距放在展开内容上，不能复用诊断页容器造成卡片错位；桌面与窄屏均核对左右边界。


## Jarvis 单一主界面、Siri 流体彩色球与手机桌面式小组件（BOB-D-015，设计规范）

1. **首屏即 Jarvis 单一交流窗口（Siri 式流体彩色球）**：
   - 置顶主助理始终呈现为简单直白的 **Jarvis 交流窗口**，不要求用户先建项目、选设备或选 Harness，也不在主助理对话中使用面向终端的字符旋转棒（`TERMINAL_ROD_FRAMES`）。
   - 核心状态由 **Siri 式流体彩色能量球（`<JarvisOrb />`）** 直观表达（无生硬状态文案）：空闲时轻柔呼吸、思考/调用工具时流光涟漪、流式回复/播报时律动脉动、需要人工审批或浏览器接管时切换暖琥珀提示态。首次进入或空对话居中呈现彩色球与简短输入引导，小组件默认收起；开始对话后彩色球平滑收拢至左上角作为主助理锚点（点击可唤起会话与视图导航）。
   - 彩色球渐变与光晕必须全部映射至明暗双模 CSS 语义变量，提供完整无障碍状态标签（`aria-label`），并在系统开启 `prefers-reduced-motion` 时自动降级为静态柔和渐变。
2. **手机桌面式小组件网格（`<JarvisWidgetGrid />`）与 3 分钟试用自改造**：
   - 主界面空白态与侧栏/首页插槽采用**类似手机桌面的可按需增删、排序小组件网格**，用户只放自己需要的信息：
     - **内建系统小组件**：如「待你确认与接管」、「今日日程与待办」、「收集箱速记」、「每日晨报摘要」、「日常任务（Routines）」；面向专业用户的「订阅额度双线」与「节点/活跃工程会话」同样收束为**可选小组件**，不再强制占据所有用户的默认顶栏菜单。
     - **对话自生成小组件（Feature Widgets）**：用户直接告诉 Jarvis 想要的小组件或面板，Bob 生成的小组件运行于无凭据沙箱 `<iframe sandbox>` 中，首帧即用本地缓存状态（`bob.state`）无闪烁绘制并后台静默刷新，严格继承宿主明暗主题 CSS 变量；每次新建或修改均在页头展示 **3 分钟试用条（保留 / 撤销）**。
   - **结构化卡片优先（`show_card`）**：主助理呈现日程、天气建议、方案对比、结果清单或审批请求时，优先输出对齐清晰的图标+字段结构化卡片，配合一句简短自然语言说明，避免大段密集 Markdown 墙。
3. **三层渐进显露与名词预算（跨层不泄密）**：
   - **L1 态**（未连接外部工作电脑、未启用外部 CLI Harness）：主界面与侧栏不渲染设备连接状态圆点、Harness 图标、按设备分组切换或订阅额度双线；保留「今天 / 收集箱 / 知识 / 我的」次级入口（可通过小组件点击或导航进入）。
   - **L2 态**（已配对「我的电脑」）：自然显露电脑在线状态、授权文件夹与 **V1→V2 成果批注对照面板**；仍不暴露底层 CLI 或协议术语。
   - **L3 态**（已接入多开发节点或外部 CLI Harness）：抽屉目录与专业小组件完整展开上文规定的原生会话目录、16px 本地静态 Harness Logo、设备路径状态与周窗口订阅额度双线；置顶主入口仍保持清爽的 Jarvis 幕僚长形态。

### 日历小时标记

全天时间轴显示 0–23，第一行代表当日 00:00，不写成 24；末行时段结束可用 24:00 表示次日边界。项目零对话计数只反映当前可显示会话，过期连接关联须按连接身份及原会话 ID 核对，不能用关联表总行数替代有效会话计数。

### 右上角额度保留边界（2026-11-12 用户澄清）

右上角保留 Codex、Antigravity、Claude 三家周额度双线，仅移除当月预算栏。不得因本地/多节点模式判断而隐藏这些栏位；无官方数据保留短横线，不伪造额度。本条覆盖此前将全部额度从默认菜单移走的描述。

待办的日期精度必须可见：只有日期显示在全天栏，不伪装精确时刻；开始/截止为同一待办的投影，编辑同一记录，不复制成额外日程。

## 日历卡片与直接调整时间

卡片以事件标题为首要内容，不常驻重复时间、“开始/截止”与项目标签；完整时间和边界语义放在悬停、可访问名称与详情中。事件按分钟定位，重叠区间分栏；不再把多个卡片挤进固定小时格截断标题。
拖动卡片按15分钟吸附调整时间；已有完整区间保持时长，拖动上/下边界独立修改开始/结束。只有一个开始或截止的待办仅移动该时间点，不凭空创建另一个边界。全天日期卡片只跨日移动，保留日期精度。最短交互区间15分钟，非法反转不保存；Escape/指针取消撤销未提交拖动。松手保存原ID及捕获版本，失败恢复原位并提示，不绕过版本冲突。点击仍可打开详情，键盘Enter可进入边界精确编辑。

日历窄屏默认今天起连续三天、桌面默认周视图，翻页步长与显示天数一致。日期/全天/小时三区必须共享列宽及滚动条预留，不允许独立计算造成错位。全天标题限行、区域限高并可滚动，不能挤走主要时间网格。

### 主助理首页默认收简
空对话不展示全设备保存/待投递计数，也不自动展开日程、灵感与例行卡片。消息发送与失败状态归属具体消息，必要的故障与审批提示保留。右上角菜单主动打开可选小组件，灵感速记仍由 Bob 悬浮入口提供；不把小组件当作已经运行的每日主动提醒。今日事项读取真实个人事务，按日期/时刻筛选，过滤已完成/取消项。

主助理首页横向居中以完整视口/对话容器为准：不滚动的根壳不预留单侧滚动槽，对话区原生滚动不占宽，空白态无灰轨道；不得用左右不等 padding 抵消错位。长对话仍支持触摸、滚轮、键盘与跳到最新。此规则覆盖首页此前单侧 stable gutter 的做法，其它独立列表按自身布局验证。

空对话的 Agent 球与简短引导作为整体，在顶部菜单和输入框之间的可用空间居中，使球本身略高于中点（约42%）；不以固定页面顶部偏移定位。小组件展开或有消息时恢复正常内容流。球使用宽范围渐变叠色与低强度慢速流动，主题色变量与减少动画偏好保留。
