## F1 基础助理

- 首次启动：添加自己的模型 Provider（BYOK）后即可对话，不要求配置服务器、Host 或 Harness。
- 对话、闪念捕获、历史检索；支持附件和图片（以平台权限为准）。
- Provider 不可用时给出具体原因和最小的下一步，不静默换模型。
- **验收**：在干净的 Windows 和 Android 设备上，从安装到第一次成功对话，全程只需填写 Provider；断网时捕获保存在本地并标为“未发送”。

## F2 跨设备连续

- 手机和 PC 看到同一事项的同一状态；草稿、阅读位置、待批准的上下文都能恢复。
- 发送状态分层显示（见 ARCHITECTURE 不变量 10）；`unknown-send` 先对账，不重发。
- **验收**：PC 发起后关闭，手机接着处理并看到同一状态；重复或乱序消息不产生重复副作用；断线期间排队的意图在恢复后按规则执行或被拒绝，并有解释。

## F3 个人事务域

- 日程与待办、Markdown 笔记、决定记录（理由、备选、证据、重审条件），能力继承自旧 App，迁移时逐项裁决去留。
- **验收**：每类数据只有一个权威位置；从旧 App 0.9.x 迁入后可以读回，可以回退。

## F4 手机让 PC 处理文件

- 在手机上选择一台可信 PC 和一个获准的工作区 → 读取指定文档 → 查看简短总结 → 批准后导出成果。
- 选择 PC 只代表选择执行位置，不代表选择本地模型；PC 离线时显示“等待”，不假装在手机上执行。
- **验收**：权限不随视图扩大；导出前需要用户批准；请求、回执、结果可以对账；通过威胁模型审阅（WP-03）。

## F5 Work 与 Harness

- 对话中的事项按需提升为 Work，保留原对话、材料和决定的引用，提升本身不扩大权限。
- Task、Execution、成果版本（父版本、hash、来源）、Verification、Review。
- 接入 DSH、AGY、Codex、Generic API；每个 Harness 的 resume、steer、cancel、attachments、artifacts、events、模型观测能力单独列出证据。
- **验收**：同一事项跨 Harness 续接，产生新的 Execution；旧版本保持只读；V1→V2 指定父版本修改。

## F6 可选常开节点

- 同一内核以无界面形态运行在常开设备上，作为 Home 或执行主机。
- **验收**：节点重启后状态可以恢复；节点离线时，客户端明确显示受影响的能力。

## F7 开源发行

- LICENSE、依赖许可证审计、去个人化、安装与升级文档、安全报告渠道；默认连接方案（BOB-D-006）。
- **验收**：在干净环境中，由非作者按文档完成安装、升级，数据保留。
