# Unified Work、Quick Note 与安装器体验修正规格

日期：2026-08-11  
状态：待用户最终复核

## 1. 修正目的

本次修正解决三个已经确认的问题：

1. 新 Work 信息架构只在 Android 生效，PC 仍显示旧的口号式页面；
2. Quick Note 底部快捷按钮宽度和间距不统一，不能自然扩展到 4–5 个动作；
3. 自定义 PC 安装器运行 `tasklist` / `taskkill` 时可能闪现终端窗口。

不增加依赖，不改变 Work Core、Goal Runtime、Capture 或同步协议，不升版本号。

## 2. PC 与 Android 共用 Work 信息架构

PC 与 Android 使用同一组 Vue 组件、同一份项目聚合数据和同一套交互语义，但严格复用 Bob 现有的响应式二级导航框架：

- `desktop-wide` 下，“工作”像“日程”和“设置”一样在左侧栏展开二级菜单，菜单为“概览 / 目标 / 任务 / 决策 / 动态”；
- `desktop-compact` 与 `mobile-native` 下，同一组二级菜单移动到内容区顶部；
- 顶部菜单上、左、右三边与内容区边界贴合，不继承项目内容的页面 padding；菜单下方的项目内容继续保留既有水平留白；
- 宽屏侧栏复用 `.settings-nav / .settings-nav-item`，窄屏与手机复用 `.mobile-tab-grid / .mobile-tab-item`，不得为 Work 自创第三套导航视觉；
- 激活项使用 Bob 现有的完整实色块选中态，不使用仅文字变色或底部短线；
- `activeWorkPanel` 是唯一导航状态源，窗口宽窄变化时选中项和内容不重置；
- 中间按最近更新时间展示全部项目；
- 项目标题行负责展开与收起，收起时显示当前 Tab 的内容数量；
- 多个项目可以同时展开，不自动收起其他项目；
- 删除旧的“持续工作核心 / 让复杂工作不断线”题头、PC 横向项目切换器及旧三栏项目面板；
- PC 只通过最大内容宽度、留白和信息密度适配大屏，不保留第二套项目内容架构；
- Android 保持顶部功能菜单和底部应用导航稳定，中间项目内容滚动。

## 3. Quick Note 几何系统

Quick Note 输入条和底部动作组共享一个唯一宽度：

```text
quickNoteWidth = min(560px, viewportWidth - 48px)
```

### 输入条

- 输入条始终以整个可用屏幕为参照，水平、垂直居中；
- 底部动作数量、Today Layer 或保存提示不得改变输入条的中心位置；
- 窗口大小变化时只重新计算共享宽度，不改变居中规则。

### 底部动作组

- 保持在安全区上方、接近屏幕底部；
- 宽度与输入条完全相同，最左和最右边界精确对齐；
- 使用等宽网格自动分配 3–5 个动作；
- 动作之间使用固定紧凑间距，不再使用 `space-between` 把按钮推向屏幕两侧；
- 每个按钮高度、内边距、图标尺寸和文字基线一致；
- 不因中文或英文标签长度改变单个按钮宽度。

### Today 计数胶囊

- “今天”文字与 `9+` 胶囊共享同一垂直中心线；
- 胶囊使用固定最小宽度和高度、`inline-grid` 二维居中与 `box-sizing: border-box`；
- 数字不依赖默认行高定位，不允许出现向下偏移；
- 1–9、9+ 和英文 Today 都必须保持视觉居中。

## 4. 安装器静默运行

- 在 Windows 自定义安装器中为 `tasklist` 和 `taskkill` 统一添加 `CREATE_NO_WINDOW`；
- 使用一个小型隐藏命令构造函数，防止后续新增系统命令再次漏配；
- 保留“检测到 Bob 正在运行”的图形确认对话框；
- 将卸载注册表的 `DisplayVersion` 从硬编码 `0.3.1` 改为读取安装器包版本；
- 不引入 Windows API 新依赖，不增加安装包体积。

## 5. 验收

### Work

- PC 和 Android 都不再显示旧口号题头；
- 宽桌面在左侧栏、窄桌面和手机在顶部显示同一组五个功能菜单；
- 选中项必须与“日程”的既有实色块选中态一致；
- 运行时切换宽窄布局后，当前功能视图保持不变且导航只出现一次；
- 多项目展开、折叠数量、任务完成和 Goal 操作结果一致；
- PC、Android 纵屏/横屏、明暗主题均无溢出。

### Quick Note

- 在窄屏、常规屏和宽屏中，输入条中心位置不漂移；
- 底部 3、4、5 个动作时均等宽，且动作组左右边界与输入条一致；
- Today 的普通数字与 `9+` 都在胶囊中精确居中。

### Installer

- Bob 未运行时安装过程不出现终端窗口；
- Bob 正在运行时仅出现 Bob 自己的图形确认对话框，不出现 `tasklist` / `taskkill` 控制台；
- 安装和取消路径均正常，注册表显示版本与当前包一致。

### Regression

- 前端测试、生产构建和安装器构建通过；
- 不增加 npm、Cargo 或运行时依赖；
- 修正完成后再提交、推送并重新运行 `release.bat`。
