# Bob — User Guide

当前统一网页已上线；桌面与Android开发包的能力范围以[CURRENT_STAGE](CURRENT_STAGE.md)为准，网页发布不代表APK同步更新。前身产品保留用于尚未完成的迁移能力（BOB-D-001）。

## 在网页继续节点上的DSH原会话

1. 打开左上角对话侧栏，搜索会话或按设备/项目浏览；每条会话显示设备标签，例如X1T DSH。
2. 按最近活动浏览，或搜索会话名称/工作目录。连接地址与Token在“设置 → 连接”管理。目录来自DSH报告，旧Online项目独立放在“历史导入项目”，不会混为节点实时项目。
3. 打开原会话，在下方输入并发送，继续同一个DSH会话；不会复制为新会话。离开前未发送文字会保存为该会话草稿。
4. 当前显示最近一段文字历史，界面提示历史可能不完整。Markdown可阅读，长内容可纵向滚动；附件与图片尚未接通。
5. 若发送结果不明确，先刷新核对原记录，不连续重发；平台不会自动重新执行。完整自助恢复仍待完善。

本轮真实验证只询问进度，没有要求修改文件。不要把DSH回复自述的测试结果当作Bob独立验收。原生Android接线与真机验收仍在待办中。

## Windows 开发版只读回复

开发宿主通过 BOB_CODEX_EXECUTABLE 指定已安装的官方 Codex 可执行文件绝对路径。认证由官方 CLI 自己管理；Bob 不读取或复制登录令牌。未配置时只能本地保存，不能据此认为模型已收到。

1. 在 Bob 输入非敏感文字，点击发送。消息先保存，再由受管执行器在独立临时目录请求文字回复。当前不用于修改项目或调用工具。
2. 运行时可点击输入框旁或当前消息下的停止；显示停止请求后需等确认退出，不能把按钮回执当作进程已结束。
3. 回复出现后会自动保存。重开后读取原记录；发生中断时先核对执行归属，不能盲目重发。
4. 当前每轮上限120秒。超时、失败或结果待核实会显示相应状态；未确认退出时暂停新执行。

此配置只启用本机只读执行，不是远端 Home 配对。独立Android开发包已安装Pixel；Home二维码候选正按下节验证，不能把安装成功当作跨设备验收。项目写入未开放。验证范围见[当前施工](CURRENT_STAGE.md)。


## 二维码连接手机（可达私网已真机验证，公网仍待实现）

1. 在电脑 Bob 中打开“连接手机”，点击“显示配对二维码”。专用连接入口也可用 `--pair-phone` 启动参数直接打开邀请页。电脑须保持在线。
2. 在手机 Bob 点击“扫码连接”，按系统提示允许摄像头，扫描电脑上的二维码。扫码图像只在本机识别，不保存或上传。
3. 扫码即确认，无需在电脑或手机重复点击。配对自动保存365天，可在Home撤销。若Home已配置只读Codex，首次扫码同时开启最长1小时的只读回复；没有配置时明确显示不可执行，不假称已启用。
4. 手机完成连接后直接发送文字，查看接收、执行与回复状态。当前限制为临时目录内只读回复，不开放真实项目修改。
5. 以后使用已保存身份重连，不必重新扫码。许可到期时在Home重新允许执行。撤销后不会自动恢复访问。

二维码短时有效；过期应重新生成。取消配对不会因为迟到回复重新绑定。摄像头被拒绝时按提示在系统设置允许后重试。手工连接仅放在“高级连接选项”用于诊断。

当前候选依赖已有局域网或私有网络可达性，这是尚未补齐公网通道的实现限制，不是产品要求手机永远与Home同Wi-Fi。扫码不会自动开通路由或更改防火墙。当前具体实现为Windows Home与Android；旧Online云端页面尚未自动成为此Home的配对入口。

扫码成功后会自动返回对话，入口和顶部提示显示“Home已配对，可以发送消息”。这表示配对已保存；电脑离线或许可失效时，不能据此假称已送达。扫描超时、取消、已读码但连接失败会分别显示提示。当前真实Pixel闭环已在可达局域网验证，异地公网连接尚未验收。

## 灵感文字与图片记录

打开“灵感速记”后直接输入文字，或点击拍照/选图。支持 PNG、JPEG、WebP，单张最多 8 MB；原图先保存到当前节点。输入后可选择已有项目、创建新项目或暂不关联，点击保存灵感。已保存图片可在知识页回看。

需要识别时先配置支持图片的视觉角色；点击识别会将图片发送给所显示的服务。建议可编辑，再明确加入记录，不会自动成为决定或提醒。扫码配对位于设置的设备连接子页。Android 拍照能力依赖系统与权限，本轮安装包尚待真机验收；图片尚不跨 Home 同步。


## 默认助理与原会话

打开默认“助理”后可直接对话，历史保存在当前实例。请先为该实例配置默认模型；手机、PC和托管网页不以配对为独立对话前提。网页助理可在用户明确要求时关联已连接节点中的现有会话，发送后显示原会话来源与接收状态，回复回到助理，点击“查看原会话”继续阅读。接收、返回回复不代表文件检查或用户验收。未知回执不自动重发。此轮未打包手机端，原生端自动关联能力不能由网页验收推定。


### 沉浸阅读与节点文件

对话右上角三点菜单选择“沉浸对话”，同一菜单可退出；偏好在本浏览器保留。原生DSH正文里的图片或文稿链接可打开预览，图片可切换原尺寸，并下载当前看到的同一份内容。当前支持有界图片/文本，网页文件展示源码。提示“当前工作区文件”表示源节点当前内容，不代表该历史消息当时的不可变版本；节点离线、文件已移走或超限会明确失败。手机安装包尚未包含本轮文件预览。


### 原会话按需阅读

打开节点会话先看最近10条并到最新位置；向上滑到顶部会载入更早10条，也可点击“加载更早的对话”。输入框一直留在底部，历史载入不清除草稿或改变正在阅读的位置。网络失败可稍后再加载。菜单仍可切换沉浸、打开列表、连接和设置。


## 项目上下文与任务卡（本地候选）

在网页“设置 → 工作间 → 项目上下文”选择宿主已授权的工作区，可查看来源文件、指纹、版本和固定任务卡。网页不能自行授权任意磁盘目录。宿主会定期核对已授权来源并更新当前胶囊；旧请求仍固定原版本，来源变化时需重新确认任务并创建新请求，不能让后台刷新改变旧任务卡。未绑定胶囊的原生会话继续沿原入口对话。此功能的原生Android宿主接线和远端完整成果治理仍有未完成项，见CURRENT_STAGE。对话附件上传尚未实现，已列RV-21；灵感照片保存与成果下载不代表对话上传能力。

## 通过一个地址连接设备

在“设置 → 连接 → 添加连接”输入设备域名，点击“检查设备”。识别出 Bob 节点后，输入机主在设备上设置的配对密码，点击“验证并连接”。密码不保存到当前客户端；连接凭证保存在本实例的安全存储中。

连接成功后显示给手机使用的二维码。二维码五分钟有效、只能兑换一次；手机获得自己的长期凭证，并不是复制浏览器的凭证。二维码过期后重新验证设备生成新的邀请。

设备必须已运行 Bob 节点，域名也必须指向它。已配置、可达、目录可读取和工具可执行是不同状态；工具本身未登录或不兼容时，不能用重新扫码解决。各节点的已验证能力和手机版本限制以 CURRENT_STAGE 为准。

### 查看订阅额度

打开右上角三点菜单查看 Codex、Antigravity、Claude Code 的额度窗口。菜单每家只显示Logo、两条线、剩余额度百分比和重置剩余时长（如2d 4h）；来源节点、具体窗口和更新时间可悬停查看。重新打开菜单会刷新缓存读回。后台约5分钟采集一次，读取失败保留旧值并显示过期。等待官方额度回报表示尚未收到可验证的数据，不等于账户没有订阅。当前 Claude 仍在等待 X1T 的官方结构化回调，不能把此前人工 /usage 查看当作已实现持续显示。
