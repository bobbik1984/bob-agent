## Windows 开发版只读回复

开发宿主通过 BOB_CODEX_EXECUTABLE 指定已安装的官方 Codex 可执行文件绝对路径。认证由官方 CLI 自己管理；Bob 不读取或复制登录令牌。未配置时只能本地保存，不能据此认为模型已收到。

1. 在 Bob 输入非敏感文字，点击发送。消息先保存，再由受管执行器在独立临时目录请求文字回复。当前不用于修改项目或调用工具。
2. 运行时可点击输入框旁或当前消息下的停止；显示停止请求后需等确认退出，不能把按钮回执当作进程已结束。
3. 回复出现后会自动保存。重开后读取原记录；发生中断时先核对执行归属，不能盲目重发。
4. 当前每轮上限120秒。超时、失败或结果待核实会显示相应状态；未确认退出时暂停新执行。

此配置只启用本机只读执行，不是远端 Home 配对。独立Android开发包已安装Pixel；Home二维码候选正按下节验证，不能把安装成功当作跨设备验收。项目写入未开放。验证范围见[当前施工](CURRENT_STAGE.md)。


## 二维码连接手机（当前候选，真机验收状态见 CURRENT_STAGE）

1. 在电脑 Bob 中打开“连接手机”，点击“显示配对二维码”。专用连接入口也可用 `--pair-phone` 启动参数直接打开邀请页。电脑须保持在线。
2. 在手机 Bob 点击“扫码连接”，按系统提示允许摄像头，扫描电脑上的二维码。扫码图像只在本机识别，不保存或上传。
3. 扫码即确认，无需在电脑或手机重复点击。配对自动保存365天，可在Home撤销。若Home已配置只读Codex，首次扫码同时开启最长1小时的只读回复；没有配置时明确显示不可执行，不假称已启用。
4. 手机完成连接后直接发送文字，查看接收、执行与回复状态。当前限制为临时目录内只读回复，不开放真实项目修改。
5. 以后使用已保存身份重连，不必重新扫码。许可到期时在Home重新允许执行。撤销后不会自动恢复访问。

二维码短时有效；过期应重新生成。取消配对不会因为迟到回复重新绑定。摄像头被拒绝时按提示在系统设置允许后重试。手工连接仅放在“高级连接选项”用于诊断。

当前候选依赖已有局域网或私有网络可达性，这是尚未补齐公网通道的实现限制，不是产品要求手机永远与Home同Wi-Fi。扫码不会自动开通路由或更改防火墙。当前具体实现为Windows Home与Android；旧Online云端页面尚未自动成为此Home的配对入口。
