## Windows 开发版只读回复

开发宿主通过 BOB_CODEX_EXECUTABLE 指定已安装的官方 Codex 可执行文件绝对路径。认证由官方 CLI 自己管理；Bob 不读取或复制登录令牌。未配置时只能本地保存，不能据此认为模型已收到。

1. 在 Bob 输入非敏感文字，点击发送。消息先保存，再由受管执行器在独立临时目录请求文字回复。当前不用于修改项目或调用工具。
2. 运行时可点击输入框旁或当前消息下的停止；显示停止请求后需等确认退出，不能把按钮回执当作进程已结束。
3. 回复出现后会自动保存。重开后读取原记录；发生中断时先核对执行归属，不能盲目重发。
4. 当前每轮上限120秒。超时、失败或结果待核实会显示相应状态；未确认退出时暂停新执行。

此配置只启用本机只读执行，不是远端 Home 配对；Android、远端同步、项目写入及安装包尚未交付。验证范围见[当前施工](CURRENT_STAGE.md)。
